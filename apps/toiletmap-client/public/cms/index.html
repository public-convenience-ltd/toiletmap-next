Editing the blog and pages here needs GitHub sign-in, which hasn't been set up for this site yet.

Until then you can still open the editor and sign in with a GitHub personal access token, or work on a local copy of the repository (Chrome or Edge).

For the site owner: turning on GitHub sign-in

Create a GitHub OAuth app and set GITHUB_OAUTH_CLIENT_ID and GITHUB_OAUTH_CLIENT_SECRET on the client worker. The steps are in apps/toiletmap-client/docs/cms.md in the repository.
